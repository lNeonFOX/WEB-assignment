# Web Assignment 1 — Report

**Name:** Torekhan Taimas
**Group:** IT-2503

## Summary of Work Process

This project was built step by step using HTML for structure and CSS for styling.
I started with the basic page skeleton, added text content, lists, images, links,
and a button, then moved on to tables, emojis, and a form. In Part 3–4, I applied
CSS in all four ways (inline, internal, external, and via selectors/classes/IDs),
experimented with the box model, positioning, sizing units, and float/clear layout,
and finished by adding a favicon and publishing the site via GitHub Pages.
